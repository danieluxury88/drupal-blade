# Documentation Bot

This project follows the ProtonSystems documentation-bot convention from the shared project
template. When maintaining this `docs/` tree:

- document the repository as it exists, using repository files and checked commands as evidence;
- preserve useful existing documentation;
- use relative links to files in this project;
- put durable decisions in `decisions/`, repeatable runbooks in `processes/`, and dated findings
  in `worklog/`;
- mark unknown project details as `TODO` or an open question instead of guessing; and
- never include credentials, private keys, database dumps, or other sensitive values.

Keep `docs/index.md` as the navigation hub and update `Last verified` dates when current-state
pages are checked.
